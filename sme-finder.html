the sme finder

375ai · 2026 · claude skill

story

375ai sells real-world video data to teams building physical AI and world models. The buyers are researchers, and researchers test every claim. When we said our capture had known geometry, fixed calibration and real distances in world units, someone was going to ask which lab had said the same thing, and who there could back it up.

So the work was to find the people who could speak to a topic, check that they were still working on it, and give them a reason to talk to us. I did that by hand: reading papers, checking who cited whom, confirming a person was still on the problem, then writing the first message.

It worked, and it did not scale. Every new topic put me back at the start. The method was the same each time, so I wrote the method down as a Claude skill and let the model run it.

what a skill is

A skill is a folder of instructions and reference files. Claude reads the description of every skill it has, loads the matching one when a request fits, and follows the file. No prompt to paste, no context to rebuild. The skill carries the procedure, an example of good output, and the rules that stop a bad one.

That matters here because the value was never a clever prompt. It was the qualification loop: which sources count as evidence, what makes a person current on a topic, and what a usable answer looks like. Those are decisions, and decisions belong in a file that runs the same way every time.

01

a topic

I give it a research area, a claim we want to defend, or a show we want to book.

02

evidence

It looks for people whose own work supports the topic: papers, code, lab pages, talks. Every name needs a link you can open.

03

a shortlist

A ranked list with why each person fits, how current their work is, and a first line that is about them, not us.

what it produced

The output was not a spreadsheet to file away. It went straight into three jobs.

  • Expert reference videos. A named expert explaining a concept in their own words, recorded end to end, for content and for sales conversations.
  • Founder placements. Founders in physical AI and computer vision brought onto shows, including Genfinity, at 32,000+ views.
  • Outreach lists. People and companies worth a real conversation, ranked so the first messages went to the ones that mattered.

what i learned

The failure mode of AI research is a confident name with nothing behind it. An expert who moved to a different field two years ago still looks perfect to a language model. So recency and a linkable source became hard gates in the skill, not preferences. If a name has no current work and no link, it does not make the list.

The second lesson is about what to return. A list of names pushes the judgement back to me. The list has to carry the decision: this person, this evidence, this reason, this opening line. Otherwise the automation only moved the typing.

The pattern generalises past hiring experts. Any research task I repeat becomes cheaper as a skill, because the second run costs one sentence, not one afternoon.
